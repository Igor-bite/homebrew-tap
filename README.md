# Igor-bite/homebrew-tap

Homebrew casks by Igor-bite.

```bash
brew tap igor-bite/tap
brew trust igor-bite/tap
brew install --cask subzero
```

Recent Homebrew loads casks from third-party taps only after `brew trust`.

| Cask | Description |
|---|---|
| [subzero](https://github.com/Igor-bite/subzero) | macOS menu bar kill switch: freezes apps when your IP leaves allowed countries or DNS leaks |
